## 2026-06-07 · localhost 与 IPv4/IPv6 回环访问差异

**核心观点**：
- `localhost` 是主机名，可能解析到 IPv6 `::1` 或 IPv4 `127.0.0.1`；`127.0.0.1` 是明确的 IPv4 loopback。
- 当开发服务器只监听 `[::1]` 时，`localhost` 可能能访问，但 `127.0.0.1` 会因为没有 IPv4 监听而连接失败。
- 端口相同不代表地址相同；`[::1]:5273` 与 `127.0.0.1:5273` 是不同地址族上的监听。

**关键框架/模型**：
- 排查顺序：先看主机名解析，再看端口监听地址，再看访问结果，最后定位启动命令或框架配置。
- Windows 常用命令：`Resolve-DnsName localhost`、`netstat -ano | Select-String ':端口'`、`Invoke-WebRequest`。
- Vite 修正入口：`npm run dev:web -- --host 127.0.0.1` 或在 `vite.config.ts` 中设置 `server.host`。

**与其他话题的关联**：
- → 健康餐业务运营：该项目的 `trading-ops-mvp` 当前由 Vite 提供前端开发服务器，端口监听策略会影响本地调试入口。
