# HMOS - 健康餐减肥服务赋能

当前版本：v1.15.0

**HMOS** 是 **Healthy Meal Operations System** 的简称，对应中文名 **健康餐交易运营中台**。

这是一个面向健康餐转单、收款、预付款、供应商下单和运营复盘的业务赋能项目。当前主要交付物是可运行的 HMOS MVP。

## 已实现能力

- 今日运营台：订单数、待付款、待下单、供应商未确认、毛利。
- 客户管理：列表优先展示，行内处理建单、余额下单、充值、收款确认、编辑和删除。
- 订单管理：列表优先展示，行内处理付款请求、确认收款、余额核销、取消、完成和退款。
- 收款充值：付款请求和充值记录/余额流水双页签，支持待付款取消/删除、充值作废冲正。
- 商品和供应商：商品套餐与供应商列表优先展示，新增/编辑表单显示字段名，供应商行内生成下单批次。
- 复盘看板：营业额、实收、预收款、核销、成本、毛利和异常池。
- 数据层：内存演示模式和阿里云 MySQL 运行模式。

## 本地运行

```powershell
cd output/01_健康餐业务运营/03_代码程序/trading-ops-mvp
npm install
npm run dev
```

默认前端地址：http://127.0.0.1:5273

默认 API 健康检查：http://127.0.0.1:4410/api/health

当前运行配置以本地 `.env.local` 为准，前端 API 默认使用同源 `/api`，便于本机和内网穿透入口共用。不要把真实数据库密码提交到 Git。
