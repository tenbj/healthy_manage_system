# 健康餐减肥服务赋能

当前版本：v1.11.1

这是一个面向健康餐转单、收款、预付款、供应商下单和运营复盘的业务赋能项目。当前主要交付物是可运行的健康餐交易运营中台 MVP。

- 子项目版本记录：[output/01_健康餐业务运营/版本记录.md](output/01_健康餐业务运营/版本记录.md)

## 已实现能力

- 今日运营台：订单数、待付款、待下单、供应商未确认、毛利。
- 客户管理：新增、编辑、删除、地址、忌口、预付款余额。
- 订单管理：独立建单、状态筛选、余额核销、取消、完成、退款。
- 收款充值：付款请求、人工确认、待付款取消/删除、充值作废冲正。
- 商品和供应商：商品套餐、供应商启停、下单批次和确认状态。
- 复盘看板：营业额、实收、预收款、核销、成本、毛利和异常池。
- 数据层：内存演示模式和阿里云 MySQL 运行模式。

## 本地运行

```powershell
cd output/01_健康餐业务运营/03_代码程序/trading-ops-mvp
npm install
npm run dev
```

默认前端地址：http://127.0.0.1:5173

默认 API 健康检查：http://127.0.0.1:4310/api/health

当前运行配置以本地 `.env.local` 为准。不要把真实数据库密码提交到 Git。
